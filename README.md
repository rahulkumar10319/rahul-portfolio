# Rahul Kumar — Personal Portfolio

A responsive personal portfolio starter built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract `Rahul-Kumar-Portfolio.zip`.
2. Open the extracted `rahul-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension and click **Go Live**.

## Before publishing
- Add your actual resume PDF at `assets/resume.pdf`. The Download Resume button is already linked to this path.
- Replace any wording you want to refine.
- Skills page is now complete (logos, hover effects). Certifications page is done (click-to-open viewer). Projects, Education and Contact now each open as their own page (projects.html, skills.html, ...). They hold placeholders until filled.
- Verify the LinkedIn profile URL and email before publishing.

## Features in this first stage
- Dark navy / purple visual direction.
- Canvas starfield with drifting and twinkling stars.
- Responsive navbar with mobile menu.
- Hero with animated role text and Download Resume button only.
- About section with the supplied biography and statistics.
- Expandable NEXORA status card.
- Footer navigation and LinkedIn, GitHub and email links.
- Reduced-motion accessibility support.

No framework or package installation is required.
